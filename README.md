# Web Development Internship - Week 2 Project

An interactive Vanilla JavaScript To-Do Application featuring DOM state updates, data persistence via browser localStorage, and conditional layout filtering.

## Core Features Implemented
* **Dynamic Task Creation:** Supports item processing via a submission button or Enter key.
* **State Updates:** Interactive completion tracking (strikethrough text) and deletion.
* **View Filters:** Filter tasks based on status (All, Active, and Completed).
* **Persistent Cache:** Keeps tasks saved even if you refresh the browser page.
* **Modular Architecture:** Split code using native ES Modules (import/export).

## Project File Layout
* index.html
* style.css
* app.js
* storage.js

## Setup Instructions
1. Clone or download this project folder.
2. Open the folder in Visual Studio Code.
3. Make sure you have the **Live Server** extension installed.
4. Right-click inside `index.html` and select **Open with Live Server**.
